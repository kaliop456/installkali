❓ FAQ

Q: Installation failed. What should I do? A: The script auto-retries 3 times. Check: ① Network connection is stable ② Storage space is 5GB+ (run df -h ~) ③ Software source is working (try switching mirrors in menu option 3) ④ Check error log: cat logs/errors-*.log

Q: How do I switch language? A: Main Menu → [14] Language Switch → Select your language. Supported: 中文, English, 日本語, 한국어, Русский, العربية

Q: How do I backup my data? A: Main Menu → [8] Backup/Restore → Choose backup type: Full (all data), Config (dotfiles only), Package List (installed packages), or Tool Directory (/tools)

Q: What systems are supported? A: Primarily designed for Termux (Android 7+). Also works on Kali Linux, Ubuntu, and Debian.

Q: How do I update installed tools? A: Re-run the script and select the tool categories to reinstall. Or use system package manager: pkg upgrade (Termux) / apt upgrade (Linux).

Q: Can I interrupt the installation? A: Yes! Press Ctrl+C for safe exit. Progress is automatically saved and will resume next time.

Q: How do I contribute? A: Fork the repo, make changes, and submit a Pull Request. Issues and feature requests welcome at github.com/kaliop456/installkali/issues.

Q: Is root required? A: No. Most features work without root. Some stealth features (MAC spoofing, TTL modification) require root access.

Q: How do I uninstall? A: Simply delete the installkali directory: rm -rf ~/installkali. To remove installed tools: pkg uninstall <toolname>.
